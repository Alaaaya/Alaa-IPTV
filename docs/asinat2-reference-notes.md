# ملاحظات مرجع Asinat 2

## حدود الاستخدام

تمت مراجعة أرشيف `streamlike-ui.zip` المرفق من المستخدم كمرجع وظيفي فقط. لا تُنقل منه أي شيفرة أو أسماء حزم أو موارد أو علامة أو ألوان مطابقة. يحتفظ التطبيق باسم **Alaa Player**، ويمتلك ثيم **Asinat 2** لغة بصرية مستقلة.

## مبادئ يعاد تفسيرها

يعتمد Asinat 2 على ثلاثة مبادئ عامة صالحة لتجربة Android TV: شريط تنقل يسار واضح، تسلسل ثابت للفئات ثم المحتوى، ومشغّل يعرض إجراءات الفيديو من دون إخفاء السياق. يطبّق التصميم هذه المبادئ عبر تدرجات فحمية دافئة، لمسة نحاسية هادئة، حواف مربعة-ناعمة، وخط تركيز فاتح ثابت بلا حركة.

تُحافظ شاشة البث على ثلاثة أعمدة: الفئات، القنوات، والمعاينة. وتحتفظ مكتبات الأفلام والمسلسلات بفئات جانبية وبوسترات للمحتوى المحدد فقط. لا يُضاف EPG أو تسجيل أو أي ميزة جديدة مفعلة تلقائياً.
